# Sources and attribution

This skill is an original Henghua orchestration/adaptation layer.

It is designed to work alongside:
- `design-taste-frontend` in this repository, curated from the Taste Skill family by Leonxlnx (MIT).
- `impeccable` in this repository, curated from Impeccable by Paul Bakaus and contributors (Apache-2.0).

The Henghua-specific material in this folder adds Windows desktop, WPF, WinUI, ERP, MES, printing, finance, DataGrid, Chinese UI, DPI, Windows 10, and commercial release-acceptance guidance.

This folder does not vendor either upstream project's full runtime, scripts, binaries, or reference trees.
